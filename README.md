# Debate Hub

My Project Summary:

I want to build a fully functional, real-world community platform called "Debatify" – a ranking and voting website where people can share their opinions on hot topics.

What I've already built:

I designed the entire UI and published a working prototype here: https://crumb-chain-71049941.figma.site/

The design includes debate topics with vote buttons (Yes/No or For/Against), real-time vote percentages, comment sections, and category filters (Culture, Sports, Tech, Science, Entertainment).

The key features I need:

Users can browse debate topics by category

Users can vote on debates (showing percentage results)

Users can leave comments

A leaderboard or ranking system to show popular debates

Clean, modern design matching my Figma prototype

Mobile-friendly

**Live app**: https://debatifyprototype.lovable.app
